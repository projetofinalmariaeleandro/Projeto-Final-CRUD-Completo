# Biblioteca Horizon - CRUD Completo

Bem-vindo à **Biblioteca Horizon**, um sistema digital de empréstimo de livros desenvolvido como projeto final.  
Este projeto implementa as operações básicas de **CRUD** (Create, Read, Update, Delete) para gerenciar usuários, livros e empréstimos.

---

##  Funcionalidades
- Cadastro de usuários com autenticação (login e senha)
- Listagem de livros disponíveis
- Empréstimo e devolução de livros
- Atualização de informações de usuários e livros
- Exclusão de registros

---

##  Tecnologias utilizadas
- **HTML5 / CSS3** → Estrutura e estilização da interface
- **PHP** → Lógica de backend
- **JSON** → Banco de dados LOCAL
- **Git/GitHub** → Controle de versão e hospedagem do código
